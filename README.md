# 寸劇タイピング道場 ── タイピングできないOL

「Excelはできないが、なぜかコードは書ける」OL（真賀田四季ふう）と、やたら丁寧で少しズレた天然AI（GPT-3.5ふう）の掛け合いを読み進めながら、要所で実際にタイピングして場面を進める、単一HTMLのタイピング教材。

**公開URL:** https://aonoa68.github.io/typing-ol-series/

北星学園大学「情報入門」の教材。Excel苦手OLシリーズ（https://aonoa68.github.io/excel-ol-series/ ）の派生。

## 特徴
- ローマ字入力エンジン内蔵（拗音きゃ/しゃ・促音っ・長音ー・ん=nn、複数表記 shi/si 等を許容）
- 記号・英字・数字もそのまま打てる（大文字は Shift）。C言語のコードや2進数も練習可
- コードには日本語訳（💬 意味）を表示
- 第7話はキーボード・ショートカット（Shift+Enter / Ctrl・⌘+C/V/A/Z/F / Esc）の練習つき。OS（Windows/Mac）で表記を出し分け
- 記録（自己ベスト等）は端末内 localStorage のみ。外部送信なし＝授業で教える「個人情報の扱い」の実践

## 全8話
1. タイピングが遅いと、AIにも置いていかれる
2. AIに頼むのも“打つ”力
3. Excelできないんです（自己紹介）
4. 寝ながらエクセル、上司はCOBOL
5. 早朝のディープラーニング
6. C言語で書いておきました
7. AIと話すキーたち
8. すべてはTになる

## 使い方
`index.html` をブラウザで開くだけ（サーバー不要）。スマホ・PC両対応。

## 教材を増やす
`index.html` 内の `STORY` 配列を編集すれば話を追加できます。
- 通常台詞：`{who:'me'|'ai'|'narration', text:'...'}`
- 打鍵課題：`{type:'type', display:'画面表示', kana:'うつひらがな', note:'任意の意味解説'}`
- ショートカット：`{type:'shortcut', combo:'shift-enter'|'copy'|..., display:'...', say:'...'}`
